Power BI Sales Dashboard

## Project Overview
This project is an interactive Sales Dashboard developed using Microsoft Power BI to analyze sales performance, customer behavior, and business trends. The dashboard helps managers make data-driven marketing and sales decisions.

## Business Objective
- Analyze overall sales performance.
- Identify top-selling products.
- Monitor customer purchase patterns.
- Support business decision-making.

## Key Insights
- Total Sales and Revenue
- Customer-wise Sales Analysis
- Product-wise Performance
- Sales Distribution
- Interactive Filters and Slicers

## Dashboard Features
- KPI Cards
- Bar Charts
- Donut Charts
- Funnel Chart
- Ribbon Chart
- Slicers
- Customer Details Table

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX
- Data Visualization

## Skills Demonstrated
- Data Cleaning
- Data Visualization
- Dashboard Design
- Data driven decision making
